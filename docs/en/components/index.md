# Components

Use semantic HTML and the stable `.ak-*` classes from the CSS package. Detailed references and live examples currently remain in Chinese; code can be used in any framework.

| Area | Reference |
| --- | --- |
| Foundation | [Colors and typography (中文)](/components/), [Helpers (中文)](/components/ak-helper) |
| Actions and content | [Buttons (中文)](/components/ak-button), [Cards (中文)](/components/ak-card) |
| Input | [Forms (中文)](/components/ak-form), [Tabs (中文)](/components/ak-tabs) |
| Feedback | [Progress and gauge (中文)](/components/ak-progress), [Notices (中文)](/components/ak-notice), [Loading (中文)](/components/ak-loading) |
| Overlays | [Dialog (中文)](/components/ak-dialog), [Popover (中文)](/components/ak-popover) |
| Display | [Levels (中文)](/components/ak-level), [Sanity (中文)](/components/ak-san), [Effects (中文)](/components/ak-fx), [Objects (中文)](/components/ak-object) |

Native HTML and headless primitives own keyboard, focus and state behavior. Keep labels, visible focus, reduced-motion support and adequate contrast when customizing the design.
